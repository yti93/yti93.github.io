# yti93.github.io

Personal site for Youssef Ibrahim — About, Resume, Talks, and Life Outside FinOps.

Static HTML and CSS, no build step or framework. Deployed via GitHub Pages ("Deploy from a branch," `main`, root).

## Structure

- `index.html` — About
- `resume.html` — Resume / work history
- `talks.html` — Conference talks and podcast appearances
- `outside.html` — Life Outside FinOps
- `style.css` — shared styles
- `images/` — talk thumbnails

Live at [yti93.github.io](https://yti93.github.io/).
